## Conventions
- Root namespace: `<Game>`. Sub-namespaces follow folders: `<Game>.Core`, `<Game>.Gameplay`, `<Game>.UI`, `<Game>.Editor`, `<Game>.Tests`.
- Assemblies: `<Game>.Runtime`, `<Game>.Editor` (Editor only), `<Game>.Tests.EditMode`, `<Game>.Tests.PlayMode`. New top-level feature folder means new asmdef only if it needs isolation.
- Code: PascalCase types and methods, `_camelCase` private fields, `[SerializeField] private` over public fields, one MonoBehaviour per file, file name equals type name.
- Data: tunables in ScriptableObjects under `Assets/_Game/Data/<Feature>/`, asset names `<Type>_<Name>` (e.g. `Enemy_Slime`).
- Scenes: `Boot` (index 0) -> `Title` -> `Game`. Additive loading through the scene loader only.
- Input: Input System actions asset `<path>`. No `UnityEngine.Input` calls.
- Tests: `[Category("M<n>")]` on every test plus a story id in the name (`M1_S02_...`) so milestone runs can filter.
- Log tags for play-verify: `[Boot]`, `[Run]`, `[Combat]`, `[Save]` (stable text, e.g. `[Run] floor=2 seed=1234`).
- Commits: `<story id>: <imperative summary>`.
